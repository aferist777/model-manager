# Model Manager

Десктопное приложение (PySide6) для ведения виртуальных моделей: придумать
персонажа, сгенерировать его лист, накопить референсы и собирать посты — всё в
одном окне, без браузерных вкладок и папок с файлами.

## Запуск

```
pip install -r requirements.txt
```

Дальше `run.bat` (или `python app/main.py`).

Ключи API вводятся в настройках приложения и ложатся в системное хранилище
учётных данных (`keyring`), а не в файлы репозитория. Переменные окружения
работают как запасной путь для headless-запусков.

Windows-only по факту: панель Instagram — это нативный Edge WebView2 через
`pythonnet`, ради нормального H.264 в рилсах. `libs/webview2/` лежит в
репозитории, отдельная установка не нужна.

## Три панели

Окно поделено вертикально, и это же его рабочий цикл слева направо:

* **Список моделей** — все персонажи и мастер создания нового.
* **Воркспейс** — вкладки по текущей модели: внешность, лист персонажа,
  черновики постов, доска референсов.
* **Instagram** — живой веб-вью аккаунта-донора рядом с досками; рилсы и
  карусели скачиваются оттуда через `yt-dlp` прямо в референсы.

## Кастинг

Модель не описывается вручную по полям. Пишется бриф — «кто нужен» — и его
разбирает агент-кастинг-директор (Hermes через OpenRouter). Он возвращает
несколько карточек кандидатов: внешность, возраст, типаж, вайб. Понравившаяся
карточка разворачивается в **лист персонажа** — фиксированный кадр 3:2 в 4K,
который дальше служит единственным источником правды о внешности: все
последующие генерации отталкиваются от него, поэтому лицо не плывёт от кадра
к кадру.

Карточки кастингов хранятся в библиотеке и переиспользуются.

## Реестр моделей

`app/generation/registry.py` — вся генерация описана данными, а не кодом. У
каждой модели указаны провайдер (Replicate / kie.ai), режимы (t2i / i2i),
сколько референсов она принимает, цена, диалект промпта и её настоящие тюнимые
параметры, снятые с живых схем.

Из этого списка попап настроек рисует себя сам, а `build_payload` переводит
общие настройки приложения в точный input конкретной модели. Добавить новую
модель — значит дописать словарь, не трогая UI.

Промпты пишутся под диалект модели, прогоняются через «кит реализма» и список
запрещённых слов, чтобы не сваливаться в глянцевый рендер. Всё, что генерит
приложение для персонажа, — 2:3.

```
model-manager/
├── app/
│   ├── generation/   реестр моделей, клиенты Replicate/kie, промпты, тайминги
│   ├── widgets/      панели, диалоги, оверлей генерации, лайтбокс
│   ├── store.py      состояние и библиотека кастингов на диске
│   ├── config.py     ключи через keyring
│   └── theme.py      тёмная тема
├── libs/webview2/    нативный хост Edge WebView2
├── tools/            snapshot.py — скриншот окна, спайки по WebView2
└── run.bat
```

## Генерация

Долгие вызовы не морозят интерфейс: пока идёт генерация, цель размывается,
поверх неё крутится прогресс с адаптивным таймером (`app/generation/timing.py`
считает ожидание по прошлым прогонам этой же модели), а управление блокируется
до результата.
